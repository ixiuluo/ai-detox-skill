# AI-Detox v3：事实优先的学术写作诊断与改写

> 面向中文学位论文、期刊论文和研究报告的 AI 特征诊断工具。v3 的核心变化：从“抓 AI 词”转为“先保事实、再判论证、最后修文风”；从“初稿模式”扩展到“后期稿模式”；增加误报控制，避免把学科术语、数字范围、合法对举当成 AI 痕迹。

## 一、四条原则

1. **事实优先于文风。** 数字、年份、口径、来源、公司事实、图表题注的错误，优先级高于任何“AI 词”。一篇文章可以没有 AI 味，但数字错了就是硬伤。
2. **误报优先于命中。** 任何规则命中后，先问四句：这是学科术语吗？这是数字范围吗？这是合法的概念对举吗？这是具体分析角度吗？四句里有一句成立，就标记为“误报”，不进入改写。
3. **论证先于句式。** 先看“结论是否超过证据”，再看句子长短。把“必要条件”改成“先行条件”，比删十个“值得注意的是”更有用。
4. **改写必须回归。** 改完数字、引注、图表、标题后，反查摘要、正文、表格、附录、封面、参考文献、图表清单和目录；不做回归审计的改写不算完成。

## 二、架构：L0—L7 + R

| 层级 | 扫描内容 | 默认风险 |
|---|---|---|
| **L0 事实与口径** | 数字的年份/单位/口径/来源，跨章节一致性，公司事实，数据截止日，图表题注 | P0 |
| **L1 词汇** | AI 空壳词、过度修饰、空洞连接、商业黑话、模糊修饰 | P2（语境敏感） |
| **L2 句式** | 句长分布、分号密度、章节目录句、模板过渡、列举结构、对举句 | P2 |
| **L3 段落** | 段落长度、开头模板、计数句、结论前置/后置 | P2 |
| **L4 论证** | 论点递进、反例与边界、因果动词强度、缺失数据、自建靶子、样本内构造/检验 | P1 |
| **L5 信息密度** | 同义反复、模糊指代、过度概括、数字幻觉、“的”字结构 | P2 |
| **L6 引用** | 引用密度、一条一号、逐事实引用、来源可追溯、GB/T 7714 | P1 |
| **L7 元书写/自指** | 承诺、预告、框架提醒、计数句、写作史、自我削弱、作者自称 | P2 |
| **R 回归审计** | 改后反查：数字、引注、图表、目录、附录、PDF 文本层 | P0 |

**优先级**：P0 事实/口径 > P1 论证/引用 > P2 文风/结构。v2 把 L1 词汇标成最高危，v3 把它降为 P2；后期稿的 AI 味通常不在词，而在模板句和论证强度。

## 三、两种模式

### 1. 初稿模式（draft）

适用于 AI 生成后未经人工清理的初稿。L1—L7 全开，词表命中按中高危处理，改写幅度大。

```
/ai-detox 扫描 draft.md --mode=draft
/ai-detox 改写 draft.md --mode=draft
```

### 2. 后期稿模式（late）

适用于已多轮修改、AI 词很少的学位论文/期刊稿。L1 降为低敏感，重点看 L0、L2、L4、L6、L7。

```
/ai-detox 扫描 thesis.md --mode=late
/ai-detox 事实 thesis.md
/ai-detox 回归 thesis.md
```

后期稿的典型残留不是“赋能/抓手”，而是：

- 计数句：“本文的研究目的有三个”“创新有三点”；
- 自指集群：连续多个段落以“本文”开头；
- 章节目录句：一句话用分号串起六章内容；
- 分号长句：一句含三个以上分号；
- 文献陈列：“X 指出、Y 发现、Z 认为”；
- 强因果动词：“决定”“证明”“必要条件”“不可能”；
- 一条多文献、引用与事实不对应；
- 摘要与正文的口径/年份/数字不一致。

## 四、S1—S10 改写策略

| 策略 | 针对层 | 核心操作 |
|---|---|---|
| S1 词汇替换 | L1 | 删 AI 空壳词，补具体事实；学科术语先查白名单 |
| S2 句式破形 | L2 | 长短交替、拆分号长句、去章节目录句、破三连排比 |
| S3 段落重塑 | L3 | 破三段论、删计数句、换开头主语、长短段交替 |
| S4 论证深化 | L4 | 补中间推理、加边界条件、把“决定”降为“同时出现” |
| S5 信息增密 | L5 | 模糊词换具体值、删同义重复、拆“的”字长定语 |
| S6 元书写清理 | L7 | 删承诺、去预告、删计数句、去写作史、去自我削弱 |
| **S7 事实校验** | L0 | 每个数字补年份/单位/口径/来源；跨章节对账 |
| **S8 论证降格** | L4 | 强因果动词按证据强度降格；缺失数据用“不可判定” |
| **S9 引用对账** | L6 | 一条一号、逐事实引用、来源可追溯、GB/T 7714 |
| **S10 回归审计** | R | 改后反查摘要/正文/表格/附录/封面/文献/图表清单/目录 |

## 六、快速规则（先记这 20 条）

1. 每个百分数/金额必须有年份、单位、口径、来源；没有就补，补不了就删。
2. “年增 55%—71%”必须写清是哪两年；否则改成“2021—2022 年年增 55%—71%”。
3. 财年不是自然年；有的公司财年截至 4 月 30 日，FY2026 的 Q4 与自然年 Q4 不是同一段时间。
4. GAAP 与调整后口径不能混用；切换口径必须说明，并检查结论是否翻转。
5. “10-K”只用于美国上市公司；港股用“年报/招股书/业绩公告”。
6. 公司总部、上市地、股票代码以最新公告为准；写“截至 YYYY-MM-DD”。
7. 一条参考文献只对应一份文件；不同公告、不同年报不能合并编号。
8. 一句话里有两个事实、两个来源，就分别标注，不用一个范围号代替。
9. 图表题名不写“数据见正文”；数据期间和口径放表注/图注。
10. 图表清单页码取“题注页”，不是“正文引用页”。
11. “不是 A 而是 B”只有在 A 是读者真会持有的误解时才用；一段最多一次。
12. “场景/维度/落地/闭环”先看是不是本文定义的术语；是就保留。
13. “——”只有修辞破折号才查；“2019—2022”是范围号，不查。
14. 一句三个以上分号，优先拆；尤其“第1章……；第2章……；……”的目录句。
15. “通过 A 使 B”才查；“通过浏览器使用”“通过网络订阅”不查。
16. “从亏损看/从粘性看/从回报看”是具体维度，保留；“从某种角度看”才查。
17. 连续三个段落以“本文”开头，换主语：研究问题、分析框架、案例选择、本章。
18. “本文有 X 个目的/意义/层面/创新”是计数句，删掉计数，直接写内容。
19. “决定/证明/必然/充分/必要/不可能/越……越……”出现时，先问证据够不够；不够就降格。
20. 缺失数据写“不可判定”，不要写成“不满足”；缺失不是负面证据。
