# AI-Detox: AI特征诊断与去除 Skill

> 学术写作AI特征检测与改写工具 — 七层扫描 + 六种改写策略 + AI话术避坑清单 + GB/T 7714参考文献规范

## 概述

AI-Detox 是一个面向 Claude Code 的学术写作辅助 Skill，用于系统性检测和去除学术文本中的 AI 痕迹。它基于大量 AI 生成学术文本与人工审校的实践经验提炼而成，覆盖七层扫描框架、六种改写策略、AI话术避坑清单、七类浮夸文风禁令，以及 GB/T 7714-2015 参考文献格式规范。

**核心洞察**: AI 写作虽内容质量尚可，但总带有特定的语言风格痕迹（词汇偏好、句式模板、段落结构），容易被检测出来。本系统系统化总结了这些特征和对应的改写策略，既是诊断工具也是写作指南。

## 使用方法

### 在 Claude Code 中启用

Skill 安装后，在 Claude Code 会话中使用以下命令激活：

```
/ai-detox 扫描 [文件路径]
/ai-detox 改写 [文件路径]
/ai-detox 参考文献 [文件路径]
```

### 七层扫描框架 (L1-L7)

对任意学术文本，逐层扫描以下七个维度：

| 层级 | 扫描内容 | 风险等级 |
|------|---------|---------|
| L1 词汇层 | AI空壳词、过度修饰副词、空洞连接词、AI高频商业词 | 🔴 高危 |
| L2 句式层 | 句式单一、过渡句模板、列举结构、"对...进行了"结构 | 🔴 高危 |
| L3 段落层 | 三段论结构、段落长度均匀、首句固定模式 | 🔴 高危 |
| L4 论证逻辑层 | 论点堆砌无递进、反例缺失、因果关系显化过度 | 🟡 中危 |
| L5 信息密度层 | 同义反复、缺乏具体细节、过度概括 | 🔴 高危 |
| L6 引用与文献层 | 引用格式不一致、泛化引用、引用与论点不匹配 | 🟡 中危 |
| L7 元书写层 | 承诺性表述、框架提醒、自我澄清、宣告式表达 | 🔴 高危 |

### 六种改写策略 (S1-S6)

| 策略 | 针对问题 | 核心操作 |
|------|---------|---------|
| S1 词汇替换 | L1 词汇层 | 替换AI高频词，补具体事实 |
| S2 句式破形 | L2 句式层 | 长短交替、主语变换、破排比 |
| S3 段落重塑 | L3 段落层 | 破三段论、不等长化、嵌入反例 |
| S4 论证深化 | L4 论证逻辑层 | 增加中间推理、引入具体案例 |
| S5 信息增密 | L5 信息密度层 | 替换模糊词为具体值、删除同义重复 |
| S6 元书写清理 | L7 元书写层 | 删承诺、去预告、减自指、消清单体 |

### 引用格式规范（GB/T 7714-2015）

参考文献须遵循：
- **顺序编码制**：按正文首次出现顺序编号，不按中英文分组
- **连续编号**：正文用 [1][2][3] 方括号，列表保持连续
- **一一对应**：所有引用文献在列表中均有对应条目
- **不重复编号**：同一文献始终使用首次编号
