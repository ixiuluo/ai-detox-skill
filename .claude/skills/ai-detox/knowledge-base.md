# AI 特征诊断与去除 Skill — 综合知识体系

> 从研笔(Paperclips)、本科论文、留学生论文等多个项目的写作与审校实践中提炼的综合能力。覆盖七层扫描框架、六种改写策略、AI话术避坑清单和写作约束全集。

---

## 一、AI 特征诊断：七层扫描框架 (L1-L7)

对任意学术文本，逐层扫描以下七个维度，标记可疑特征。

### L1 — 词汇层（最容易被 AI 检测）

| 特征 | 典型模式 | 风险等级 |
|------|---------|---------|
| **AI空壳词** | "在此背景下"、"基于此"、"在此基础之上"、"总体来看"、"综合来看" | 🟡 中危 |
| **过度修饰副词** | "值得注意的是"、"毋庸置疑"、"显而易见"、"不可忽视的是"、"更为重要的是" | 🔴 高危 |
| **空洞连接词** | "此外"、"另一方面"、"与此同时"、"总而言之"、"综上所述" | 🟡 中危 |
| **固定搭配重复** | "扮演着重要角色"、"发挥着关键作用"、"占据着重要地位" | 🔴 高危 |
| **过度正式词汇** | "本研究旨在"、"有鉴于此"、"有鉴于" | 🟡 中危 |
| **AI高频商业词** | "赋能"、"助力"、"抓手"、"落地"、"对齐"、"闭环"、"颗粒度"、"维度"、"场景"、"痛点"、"底层逻辑"、"顶层设计" | 🔴 高危 |
| **模糊修饰** | "具有一定的"、"某种程度上的"、"相关的"、"较为/比较"、"一定的" | 🟡 中危 |
| **空洞比较级** | "更好的"、"更有效的"、"相应的"、"相关方面" | 🟡 中危 |
| **不必要的自我引用** | "本文将从以下几个方面进行论述" 但无实际内容 | 🟡 中危 |

**诊断方法**：每 500 字中以上词汇频次 >3次 → 警告。

### L2 — 句式层

| 特征 | 典型模式 | 风险等级 |
|------|---------|---------|
| **句式单一** | 连续 3+ 句主谓宾结构，长度接近（25-40字） | 🟡 中危 |
| **每段主题句明显** | 每段第一句都是"XX 是..."标准定义句 | 🟡 中危 |
| **过渡句模板** | "在...方面"、"从...角度来看"、"就...而言" | 🔴 高危 |
| **列举结构过度** | "首先...其次...再次...最后"或"第一...第二...第三..."频繁出现 | 🟡 中危 |
| **设问句使用** | "为何...？这是因为..."自问自答式 | 🟡 中危 |
| **AI三板斧句式** | "提高了……优化了……促进了……" 三连排比 | 🔴 高危 |
| **X不仅是……更是……也是……** | 三层递进结构 | 🔴 高危 |
| **"对……进行了……"结构** | "对相关数据进行了统计和分析" | 🔴 高危 |
| **"通过……使……"嵌套** | "通过培训，使员工掌握了销售技巧" | 🟡 中危 |

**诊断方法**：提取前10句，逐句统计字数。标准差 <8 → 句式过于均匀，疑 AI。

### L3 — 段落层

| 特征 | 典型模式 | 风险等级 |
|------|---------|---------|
| **三段论结构** | 每段：主题句 → 展开(3-5句) → 总结句 | 🔴 高危 |
| **段落长度均匀** | 所有段落长度接近（±20%） | 🟡 中危 |
| **过渡生硬** | 段落之间缺乏逻辑过渡，用连接词硬转 | 🟡 中危 |
| **首句固定模式** | "近年来，XX 作为..." 开头多段 | 🔴 高危 |
| **无短段落** | 没有 1-2 句强调段或过渡段 | 🟡 中危 |
| **一段塞多层意思** | 六维度、三阶段、亏损论证全塞在同一段 | 🟡 中危 |

### L4 — 论证逻辑层

| 特征 | 典型模式 | 风险等级 |
|------|---------|---------|
| **论点堆砌无递进** | 多个论点平行排列，无层次关系 | 🔴 高危 |
| **论证链条缺失** | 提出论点 → 直接结论，缺中间推理环节 | 🟡 中危 |
| **反例/边界缺失** | 只讲正面，不提局限性或反例 | 🟡 中危 |
| **抽象论述多，具体案例少** | 大量"理论上"、"原则上"，缺少具体数据/案例 | 🔴 高危 |
| **因果关系显化过度** | "因为...所以..."、"正是由于..." 过度使用 | 🟡 中危 |
| **万能逻辑链条** | "因为 A，所以 B，进而 C，从而 D" 完整推理链 | 🔴 高危 |

### L5 — 内容信息密度层

| 特征 | 典型模式 | 风险等级 |
|------|---------|---------|
| **信息密度低** | 大量文字传达少量信息，水词填充 | 🔴 高危 |
| **同义反复** | 同一观点换不同说法反复出现 | 🔴 高危 |
| **缺乏具体细节** | "某个算法"、"某种方法"、"相关研究"等模糊指代 | 🟡 中危 |
| **过度概括** | "被广泛应用"、"已有很多研究" 不给出处 | 🟡 中危 |
| **数字幻觉** | 出现具体数字但缺乏上下文验证 | 🔴 高危 |
| **"的"字堆叠** | 定中结构过复杂："对航空附加产品这一核心概念在理论上的全面梳理" | 🟡 中危 |

### L6 — 引用与文献层

| 特征 | 典型模式 | 风险等级 |
|------|---------|---------|
| **引用格式不一致** | 混用 [1]、[作者, 年份]、脚注 | 🟡 中危 |
| **引用位置固定** | 所有引用都在句末 | 🟡 中危 |
| **引用量过低或过高** | 学术论文每段至少 1-2 引用，缺少则疑 AI | 🟡 中危 |
| **泛化引用** | "研究表明..." 无具体作者和年份 | 🔴 高危 |
| **引用与论点不匹配** | 引用位置但与上下文论点无关 | 🟡 中危 |

### L7 — 元书写层（AI 独特的自我指涉）

| 特征 | 典型模式 | 风险等级 |
|------|---------|---------|
| **承诺性表述** | "将在下一节讨论"、"详见后文" 但实际没有 | 🔴 高危 |
| **框架提醒** | "本文的结构安排如下"、"本节将从以下方面阐述" | 🟡 中危 |
| **过度结构化** | "本节分为三个部分：第一部分...第二部分...第三部分..." | 🔴 高危 |
| **不必要的预览** | 在段末预告下一段内容 | 🟡 中危 |
| **自我澄清** | "需要指出的是"、"需要说明的是"、"值得注意的是" | 🟡 中危 |
| **宣告式表达** | "本文正是对这一空白的回应"类句式 | 🔴 高危 |
| **优先权声明** | "首次"、"首创" 等自我标注创新 | 🟡 中危 |
| **"不是……而是……"泛滥** | 一段出现两次以上 → 喊口号感 | 🟡 中危 |

## 二、七类浮夸文风禁令

| # | 类型 | 说明 | 示例 |
|---|------|------|------|
| 1 | **学术装饰** | 不必要的学术定语和修饰词 | "探索性"双案例比较 → 双案例比较 |
| 2 | **大词** | 超出论证需要的概念升级 | 范式转换 → 转变 |
| 3 | **文学隐喻** | 将信息陈述包装为画面描写 | "照亮了转型的一个侧面" → "各有分工" |
| 4 | **冗余修饰** | 同一信息用不同措辞重复强调 | "差异鲜明"+"差异如此之大" |
| 5 | **学术黑话** | 圈内术语堆叠，外行不透明 | "多维度协同展开" → "技术、组织、生态系统的同步变化" |
| 6 | **渲染句式** | 用情节感替代事实陈述 | "并非孤立事件" → "这不是巧合" |
| 7 | **口号式表达** | 压缩口号替代具体描述 | "一客一策" → "个性化适配" |

## 三、AI 风格改写 — 六种改写策略 (S1-S6)

### S1 — 词汇替换（针对 L1 问题）

| AI 原词 | 替换方案 |
|---------|---------|
| "值得注意的是" | 直接删除，或替换为具体理由（如"该结果与 Smith(2020)的发现一致"） |
| "毋庸置疑" / "显而易见" | 删除，改为具体论据或"事实表明"、"数据显示" |
| "扮演着重要角色" / "发挥着关键作用" | "是...的关键因素" 或直接描述具体作用 |
| "本研究/本文" | 根据语境替换为"该工作" / 被动语态 / "实验结果表明" |
| "综上所述" | 替换为具体总结（如"上述分析揭示了..."） |
| "不可忽视" / "更为重要的是" | 删除，用段落层次自然体现重要性 |
| "对此背景" / "基于此" / "在此基础之上" | 直接说具体原因或删掉 |
| "从……角度来看" | 指明具体哪个角度 |
| "赋能" / "助力" | 帮助/支持/提升，最好不用 |
| "抓手" | 方法/手段/途径/直接说具体事物 |
| "落地" | 实施/执行/做到/具体做 |
| "对齐" | 沟通一致/协调 |
| "闭环" | 完成/结束/用具体描述替代 |
| "颗粒度" | 细节/细致程度 |
| "维度" | 方面/层面 |
| "痛点" | 问题/困难/具体描述 |
| "底层逻辑" | 根本原因/核心/直接说理 |
| "方法论" | 方法/做法/具体描述 |

**原则**：删掉一个 AI 词，补一个具体事实。不删不补 = 文字变弱。

### S2 — 句式破形（针对 L2 问题）

| 操作 | 示例 |
|------|------|
| **长短交替** | 将 1 个长句(40字)拆为 短(15字) + 长(35字) |
| **主语变换** | 避免连续句以同一主语开头（"本文...本文...本文"） |
| **插入语/括号** | 在长句中插入括号补充或同位语 |
| **问句打断** | 偶尔用设问或反问打破平铺直叙（节制使用） |
| **倒装/强调** | 状语前置："与经典方法不同，本方法..." |
| **破三段论排比** | "提高了……优化了……促进了……" 只保留一两个重点 |
| **去 "对……进行了"** | 改为主动语态："我统计了数据，分析了变化趋势" |
| **化 "通过……使"** | 改为：去掉"通过"或"使"，保留一个 | 
| **去 "X不仅是……更是……也是……"** | 两层意思就够了，三层一定是 AI |

**黄金比例**：一段 5-7 句中，最短句 <20 字，最长句 >40 字。

### S3 — 段落重塑（针对 L3 问题）

| 操作 | 做法 |
|------|------|
| **破三段论** | 打散主题句-展开-总结的模式。将总结句变为过渡句或删除 |
| **不等长化** | 段落长度差异化：一段 4 句、一段 8 句、一段 2 句 |
| **嵌入短段** | 在长篇论述中插入 1-2 句的强调段或过渡段 |
| **去首句模板** | 替换"近年来"为具体时间锚点（"2020年以来"） |
| **嵌入反例段落** | 有意插入一个简短的制约/反论点段落 |
| **一段只讲一层意思** | 不要让段落承担过多论点的展开 |

### S4 — 论证深化（针对 L4 问题）

| 操作 | 做法 |
|------|------|
| **增加中间推理** | A→C 中补充 A→B→C |
| **引入具体案例** | 每个抽象论点配一个具体例证 |
| **插入边界条件** | 明确指出"该方法适用于...，但不适用于..." |
| **增加对比论证** | "与 Zhang(2022)不同，本方法..." |
| **弱化因果链** | "这使得" → "这种情况下" / "基于此" |
| **砍万能逻辑链** | "进而""从而"只说第一层因果关系就够了 |

### S5 — 信息密度提升（针对 L5 问题）

**五步增密法**：
1. 圈出每个概括性词语（"相关"、"某种"、"大量"）
2. 替换为具体值（"7篇文献"、"Transformer模型"、"300个样本"）
3. 删除同义重复句（保留信息最丰富的一句）
4. 压缩冗余修饰（"非常显著的" → "显著的"）
5. 合并相邻短句为一个信息丰富的长句

**"的"字检测**：去掉"的"字重读 — 如果仍然通顺，说明定中结构过多。

### S6 — 元书写清理（针对 L7 问题）

| 操作 | 做法 |
|------|------|
| **删承诺** | "将在下一节讨论" → 直接在下一节写，或删除 |
| **去预告** | "本节将从三方面..." → 直接开始论述 |
| **减自指** | "本文提出了" → "该工作提出" / "本研究提出" |
| **去澄清** | "需要指出的是" → 直接指出，前面不铺垫 |
| **消清单体** | "第一、第二、第三" → 混合使用段落结构和逻辑词 |
| **删宣告** | "本文正是对这一空白的回应" → 直接陈述研究做了什么 |
| **去标签** | 不用"领域创新/理论创新/方法创新"公式化标签 |

**铁律**：每条元书写语句删除后，检查上下文是否仍然通顺。

## 四、AI 高频标点特征

| 标点 | AI 特征 | 处理 |
|------|---------|------|
| **破折号** | AI 最被滥用的标点。插入语、转折、举例全可用逗号或句号替代 | 全文谨慎使用 |
| **中文冒号** | AI 高频，尤其"是："、"为："结构。总起、解释、引出句子都可用逗号替代 | 全文谨慎使用 |
| **分号** | 论文中除非排比列举，否则少用 | 拆成句号 |
| **引号** | 滥用引号标注"关键词" | 只在直接引语、术语、书名号替代中使用 |

## 五、快速自测清单

写完一段/章后，逐项检查：

- [ ] 将文中的"的"字去掉重读——如果仍然通顺，说明定中结构过多
- [ ] 是否有"对……进行了"结构？——如有，改用主动语态
- [ ] 是否有三个以上破折号？——如有，大多数可改逗号或句号
- [ ] 是否有"首先……其次……再次……最后"完整链条？——如有，砍掉后半
- [ ] 任意连续 100 字是否可以完全删掉而不影响理解？——如有，那段是废话
- [ ] 有没有一句话里有三个以上的"的"字？——如有，拆短
- [ ] 有没有"通过 A，使 B 更 C"的句式？——如有，改为"B 更 C"
- [ ] 有没有"对……起到了一定的……作用"？——如有，整句删掉
- [ ] 有没有任何读起来像标语/口号的对仗句？——如有，一定来自 AI
- [ ] 把任意一段输入 AI 检测器——如果标记概率超过 30%，重写
- [ ] 删掉一句装饰性定语——如果不影响理解，说明多余
- [ ] 外行（非本专业）能否看懂每个术语？——如有，加解释
- [ ] 前章是否泄露了后章的细节？——如有，删掉
- [ ] 多个创新点是否有注水？——三个扎实好过四个注水

## 六、高效改写流程

```
输入文本
    │
    ▼
Step 1: 七层扫描（先诊断，后修改）
    │   高危优先: L7 元书写 > L1 词汇 > L5 密度
    │   每个 layer 独立标记严重程度
    │
    ▼
Step 2: 分层改写（从最上层到底层）
    │   元书写清理 (S6) — 删承诺、去预告
    │   词汇替换 (S1) — 替换 AI 高频词
    │   句式破形 (S2) — 打破模板化句式
    │   段落重塑 (S3) — 差异化段落结构
    │   论证深化 (S4) — 补充推理链条
    │   信息增密 (S5) — 提升信息密度
    │
    ▼
Step 3: 复查（关键！）
    │   再次运行七层扫描
    │   对比改写前后评分
    │   逐项确认高危特征已消除
    │
Step 4: 快速自测清单（第四部分）
    │
    ▼
输出改写后文本 + 诊断摘要
```

## 七、诊断报告格式

改写后给出结构化摘要：

```json
{
  "summary": {
    "totalIssues": 12,
    "highRisk": 3,
    "mediumRisk": 6,
    "lowRisk": 3,
    "overallAssessment": "该文本AI特征明显，集中在词汇层(L1)和模板化结构(L3)，建议全面改写"
  },
  "layers": [
    {
      "layer": "L1_词汇",
      "severity": "high",
      "findings": [
        {"pattern": "过度副词", "count": 5, "examples": ["值得注意的是", "毋庸置疑"], "suggestion": "替换为具体论据"},
        {"pattern": "空洞连接", "count": 7, "examples": ["此外", "另一方面"], "suggestion": "减少至2处，或用逻辑代替"}
      ]
    }
  ],
  "rewritePlan": [
    {"priority": 1, "action": "词汇替换", "targets": ["L1"], "method": "S1"},
    {"priority": 2, "action": "段落重塑", "targets": ["L3"], "method": "S3"},
    {"priority": 3, "action": "信息增密", "targets": ["L5"], "method": "S5"}
  ]
}
```

检测通过标准：
- 七层每层得分 < 0.3（每层检测到的 AI 特征比例低于 30%）→ 通过
- 任何一层 ≥ 0.3 → 需针对该层改写
- 高危特征(🔴)出现累计 ≥ 3 项 → 需全面改写

## 八、参考文献 GB/T 7714-2015 格式规范

### 8.1 核心原则

1. **顺序编码制**：参考文献按在正文中首次出现的先后顺序编号，不按中英文分组，不按作者姓氏字母排序。
2. **连续编号**：正文引用用 [1], [2], [3]... 方括号上标，参考文献列表保持 1, 2, 3... 连续。
3. **一一对应**：正文中引用的文献必须在参考文献列表中列出，列表中不得出现正文未引用的文献（必要的阅读资料可另附）。
4. **同一文献不重复编号**：同一文献在正文多处被引用时，始终使用首次出现时的编号。

### 8.2 各类型文献格式

**期刊文章 [J]**
```
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```
示例：
```
[1] 管传靖. 大国战略竞争与全球价值链的地缘政治转向[J]. 外交评论(外交学院学报), 2024, 41(6).
[2] Kobrin S J. Political risk: A review and reconsideration[J]. Journal of International Business Studies, 1979, 10(1): 67-80.
```

**专著/书籍 [M]**
```
[序号] 作者. 书名[M]. 出版地: 出版社, 出版年.
```

**学位论文 [D]**
```
[序号] 作者. 题名[D]. 出版地: 出版单位, 年.
```

**报告 [R]**
```
[序号] 作者. 报告名[R]. 出版地: 出版单位, 年.
```
示例：
```
[19] Apple Inc. Form 10-K for the fiscal year ended September 28, 2024[R]. Cupertino: Apple Inc., 2024.
```

**在线资源 [EB/OL]**
```
[序号] 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
```
示例：
```
[21] Ministry of Electronics and Information Technology, Government of India. Production linked incentive scheme for large scale electronics manufacturing[EB/OL]. (2020-04-01)[2026-06-01]. https://www.meity.gov.in/content/production-linked-incentive-scheme-large-scale-electronics-manufacturing.
```

### 8.3 作者著录规则

| 语种 | 规则 | 示例 |
|------|------|------|
| 中文 | 姓在前名在后，全名不缩写 | 刘娅, 梁明, 徐斯, 等 |
| 英文 | 姓在前全大写，名用首字母缩写 | Kobrin S J, Gereffi G |
| 3人以上 | 中文用"等"，英文用"et al." | Meyer K E, Estrin S, Bhaumik S K, et al. |

### 8.4 标点与格式要点

- 题名与文献类型标识之间用句点（.）连接
- 期刊文章刊名后直接用逗号（,），不空格
- 卷号与期号之间用括号：44(1)
- 起止页码之间用短横线：67-80
- 英文期刊名保持原样，不大写每个单词
- 英文题名仅首单词和专有名词大写（句子式大小写）
- 中文文献用中文标点，英文文献用英文标点

### 8.5 常见错误清单

| ❌ 错误用法 | ✅ 正确用法 |
|------------|------------|
| 中英文分组排列 | 按首次出现顺序混合排列 |
| 英文作者名写全 | 姓全称+名首字母：Kobrin S J |
| 作者间用逗号 | 英文用逗号，中文用逗号 |
| 遗漏文献类型标识 | 必须标注 [J] [M] [D] [R] [EB/OL] |
| 引用格式不统一 | 全文统一使用顺序编码制 |
| 正文未引用的文献列入 | 参考文献列表只收入正文引用的文献 |
| 同一文献多编号 | 同一文献始终使用首次编号 |

### 8.6 快速自检清单

- [ ] 参考文献编号顺序与正文首次出现顺序一致
- [ ] 所有正文 [N] 均有对应参考文献条目
- [ ] 所有参考文献条目均在正文中被引用
- [ ] 编号连续无跳号
- [ ] 英文作者姓在前、首字母缩写
- [ ] 3人以上作者已用"等"或"et al."省略
- [ ] 每种文献类型标识正确
- [ ] 英文题名使用句子式大小写
- [ ] 起止页码使用短横线
- [ ] 卷期号格式正确：卷(期)

**Why:** GB/T 7714-2015 是中国学术论文参考文献的国家标准，采用顺序编码制，要求参考文献严格按正文首次出现顺序排列。掌握这套规范有助于减少因文献格式问题导致的返工，避免"中英文分组排列"等常见错误。
**How to apply:** 撰写或修改论文时，按 8.1-8.6 逐项核对参考文献格式。正文引用标注 [N] 的同时，即可在参考文献列表中按顺序添加对应条目，保证编号顺序与正文一致。
