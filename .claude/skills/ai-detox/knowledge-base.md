# AI 特征诊断与去除 Skill v3 — 综合知识体系

> v3 不是 v2 的“加词表”，而是换了诊断顺序：**L0 事实与口径 → L4 论证强度 → L6 引用对账 → L1/L2/L3/L5/L7 文风 → R 回归审计**。  
> v2 适合 AI 初稿；v3 同时适合初稿和已经多轮修改的后期稿。后期稿的 AI 味通常不在“赋能/抓手”，而在计数句、自指集群、章节目录句、分号长句、文献陈列和强因果动词。

---

## 0. 两种模式与四条原则

### 0.1 两种模式

| 模式 | 适用对象 | 扫描重点 | 改写幅度 |
|---|---|---|---|
| `draft` 初稿模式 | AI 生成后未经人工清理 | L1—L7 全开，词表命中按中高危 | 大 |
| `late` 后期稿模式 | 已多轮修改的学位论文/期刊稿 | L0、L2、L4、L6、L7；L1 只查装饰性商业词 | 小，优先事实与论证 |

### 0.2 四条原则

1. **事实优先于文风。** 数字、年份、口径、来源、公司事实、图表题注的错误，优先级高于任何“AI 词”。
2. **误报优先于命中。** 规则命中后先问：学科术语？数字范围？合法对举？具体角度？任一成立即标“误报”，不进入改写。
3. **论证先于句式。** 先看结论是否超过证据，再看句子长短。“必要条件”改成“先行条件”，比删十个“值得注意的是”更有用。
4. **改写必须回归。** 改完数字、引注、图表、标题后，反查摘要、正文、表格、附录、封面、参考文献、图表清单和目录。

## 1. L0 事实与口径层（P0，先于一切文风）

### 1.1 数字四要素

任何百分数、金额、客户数、增长率，必须能回答四个问题：

| 要素 | 检查 |
|---|---|
| **期间** | 哪一年/季度/财年？是全年、半年还是单季？ |
| **单位** | 百万/亿/美元/人民币？百分比还是百分点？ |
| **口径** | GAAP 还是调整后？合并口径还是分部？期末还是时点？ |
| **来源** | 10-K/10-Q/招股书/业绩公告/官网？页码或行项？ |

缺一项，就是 P0。示例：

- ❌ “客户数年增 55%—71%” → ✅ “客户数 2021—2022 年年增 55%—71%”
- ❌ “毛利率从 74.8% 降至 30.9%” → ✅ “亏损期毛利率 74.8%→60.6%，FY2026 进一步降至 30.9%”
- ❌ “2026Q3 数据见正文” → ✅ 题名只写“2019—2026H1”，Q3 数据放表注或正文
- ❌ “三家企业 2019—2026 年的 10-K” → ✅ “三家企业的年报、招股书与业绩公告”（港股没有 10-K）

### 1.2 财年与自然年

- 美国公司多为自然年；也有的公司财年截至 4 月 30 日。
- 有的公司财年截至每年 4 月 30 日；FY2026 的 Q4 是 2026 年 2—4 月，2026 年 5 月发布的是 FY2026 初步业绩，不是 FY2027 Q1 的经营数据。
- 港股公司按港交所年度/中期业绩公告，半年报与年报口径不同。
- 同一张表里混用自然年和财年，必须加注。

### 1.3 口径一致性

- GAAP 营业利润率与“剔除股权激励后的营业利润率”不能混用；切换口径必须说明，并检查结论是否翻转。
- “净收入留存率（NRR）”与“客户留存率”是两个指标；不能在同一格并置后让读者直接比较。
- “净美元留存率”是部分美股公司的披露口径，可在首次出现时注明“即 NRR”。
- 毛利率、营业利润率、净利率、经营现金流/收入，各算各的，不互相替代。

### 1.4 公司事实与来源时效

- 总部、上市地、股票代码、CEO、重组计划，以最新公告为准；写“截至 YYYY-MM-DD”。
- 公司公告、10-K、招股书、业绩公告、新闻稿，各是各的来源；不能用一个首页 URL 代替具体公告。
- 数据截止日要写清；季度数据发布后，摘要、正文、表格、附录、封面要同步。
- 一条参考文献只对应一份文件；不同公告、不同年报不能合并编号。

### 1.5 图表与页码

- 图题/表题不写“数据见正文”“详见后文”；题名只描述图是什么，数据期间和口径放图注/表注。
- 图/表必须在正文中有引用；引用句应说明“见图X-X”或“见表X-X”。
- 图表清单页码取“题注页”，不是“正文引用页”。正文里“如图5-7所示”所在页和“图5-7 某公司收入结构”题注页可能差1—2页。
- 表格跨页时，表题在首页；清单页码以表题所在页为准。

### 1.6 摘要/正文/表格/附录对账

改一个数字，至少反查六处：摘要、正文、表格、附录、封面数据截止日、参考文献/公告日期。  
常见错误：摘要用了后续期数字，正文用了判定期数字；表格改了，摘要没改；正文改了，附录没改。

## 2. L1—L7 扫描细则

### L1 词汇层（P2，语境敏感）

| 特征 | 典型模式 | v3 判定 |
|---|---|---|
| AI 空壳词 | “在此背景下”“基于此”“总体来看”“综合来看” | 命中即查；能删就删，不能删就换成具体原因 |
| 过度修饰副词 | “值得注意的是”“毋庸置疑”“显而易见”“不可忽视的是” | 高危；优先删除，补具体论据 |
| 空洞连接词 | “此外”“另一方面”“与此同时”“综上所述” | 中危；连续出现或段段都有才查 |
| 固定搭配 | “扮演着重要角色”“发挥着关键作用”“占据着重要地位” | 高危；改成具体作用 |
| 商业黑话 | “赋能”“抓手”“落地”“对齐”“闭环”“颗粒度”“痛点”“底层逻辑”“顶层设计” | 先看语境；装饰性用法才改，术语/引用原词保留 |
| 模糊修饰 | “具有一定的”“某种程度上的”“相关的”“较为/比较” | 中危；能换成具体程度就换 |
| 重要形容词 | “核心”“关键”“重要”“显著”“有效” | 频次阈值：每300字超过1次，或连续段落反复出现，才查 |
| 自指 | “本文”“本研究”“作者” | 看密度和段落开头集群，不按总次数一刀切 |

**v3 新增：术语白名单。** 以下词在本文中可能是框架术语，不能按 AI 黑话处理：

| 术语 | 允许条件 |
|---|---|
| 维度 | 作为分析框架的固定维度（如“五维结构”） |
| 场景 | 指具体业务场景/应用场景/场景化合同，有上下文 |
| 落地 | 指方案实施/执行，有具体对象 |
| 闭环 | 指流程完成/反馈回路，有定义 |
| 赋能 | 仅在引用文献原题、政策术语或他人概念时保留；自己论述改“支持/提升/帮助” |
| 核心/关键 | 每300字不超过1次；超过就改成具体作用 |

**判定方法**：先跑词频，再逐条看上下文；词频只用来排序，不用来定罪。

### L2 句式层（P2）

| 特征 | 典型模式 | v3 判定 |
|---|---|---|
| 句式单一 | 连续3+句主谓宾，长度接近（25—40字） | 句长标准差<8才查 |
| 过渡句模板 | “在……方面”“从……角度来看”“就……而言” | 具体角度（从亏损看/从契约角度）保留；空洞角度才查 |
| 列举过度 | “首先……其次……再次……最后”或“第一……第二……第三……” | 真正的分类保留；每段都用、或用来代替推理才查 |
| 设问自答 | “为何……？这是因为……” | 论文中少用；出现即查 |
| 三连排比 | “提高了……优化了……促进了……” | 高危；只留一两个重点 |
| 三层递进 | “X不仅是……更是……也是……” | 高危；两层就够 |
| “对……进行了……” | “对相关数据进行了统计和分析” | 改主动语态 |
| “通过……使……” | “通过培训，使员工掌握了……” | 只查“通过A使B”的因果句；“通过A使用B”不查 |
| 章节目录句 | “第1章……；第2章……；第3章……” | 高危；删掉或拆成两句，结构交给图1-1/1-2 |
| 分号长句 | 一句含3+分号，或全文>20%句子含分号 | 高危；优先拆“四个意味着”“三个条件”类句子 |
| 数字范围/连接号/缺省号 | “2019—2022”“亏损—粘性—回报”、表格“—” | 不查；只有修辞破折号“——”才查 |
| 概念对举 | “不是A而是B” | 语义判断：A是真实误解/常见误判→保留；A是稻草人、或一段两次以上→改写 |

**v3 新增：句长和分号阈值。**

- 句长标准差 <8 → 句式过于均匀，查；
- 超过25%的句子 >80字 → 长句偏多，查；
- 含分号句子 >20%，或单句3+分号 → 分号长句，查；
- 但“第一……；第二……；第三……”的真实分类不算分号长句。

### L3 段落层（P2）

| 特征 | 典型模式 | v3 判定 |
|---|---|---|
| 三段论 | 每段：主题句→展开→总结句 | 连续多段都这样才查 |
| 段落长度均匀 | 所有段落长度接近（±20%） | 段长标准差<20才查 |
| 首句固定 | “近年来，XX作为……”开头多段 | 连续3段以上才查 |
| 无短段落 | 没有1—2句的强调段/过渡段 | 中危；适当插入短段 |
| 一段多层 | 六维度、三阶段、亏损论证全塞一段 | 中危；一段只讲一层 |
| **计数句** | “本文的研究目的有三个”“创新有三点”“分为四个层面” | 高危；删掉计数，直接写内容 |
| **自指集群** | 连续3+段以“本文”开头 | 中危；换主语：研究问题/分析框架/案例选择/本章 |
| 结论前置 | 段首先给结论，再展开 | 不查；这是学术写作的正常结构，不是AI特征 |

### L4 论证层（P1）

| 特征 | 典型模式 | v3 判定 |
|---|---|---|
| 论点堆砌 | 多个论点平行排列，无递进 | 高危；补“问题—分歧—缺口”或“条件—机制—边界” |
| 论证链缺失 | 论点→结论，缺中间推理 | 中危；补A→B→C |
| 反例/边界缺失 | 只讲正面，不提局限 | 中危；每个大结论至少一段边界 |
| 抽象多、案例少 | 大量“理论上”“原则上” | 高危；补具体数据/案例 |
| 因果显化过度 | “因为……所以……”“正是由于……” | 中危；弱化万能逻辑链 |
| **强因果动词** | “决定”“证明”“必然”“充分条件”“必要条件”“不可能”“越……越……” | 高危；必须匹配证据强度，否则降格 |
| **缺失数据当负面** | 未披露→“不满足”“没有做到” | 高危；改为“不可判定”，不计入满足/不满足 |
| **自建靶子** | 把“阶段顺序假设”说成文献模型，实际是自己抽象的 | 中危；标明“分析性对照”，不要冒充文献定论 |
| **样本内构造/检验** | 用同一批案例归纳标准，又说“检验其区分力” | 高危；改为“说明/应用”，并披露样本选择偏误 |

**v3 新增：证据强度降格表。**

| 原句 | 证据不足时的改法 |
|---|---|
| “A决定了B” | “A与B同时出现差异；单独效应尚未分离” |
| “A是B的必要条件” | “在本文观察的案例中，A是B的先行条件，不构成必要条件检验” |
| “这证明了……” | “这与……一致/这为……提供了案例证据” |
| “不可能……” | “在本文样本中未出现……” |
| “越……越……” | “在两个案例中呈现……” |

### L5 信息密度层（P2）

| 特征 | 典型模式 | v3 判定 |
|---|---|---|
| 信息密度低 | 大量文字传达少量信息 | 高危；删水词 |
| 同义反复 | 同一观点换说法反复出现 | 高危；保留信息最丰富的一句 |
| 模糊指代 | “某个算法”“某种方法”“相关研究” | 中危；换具体名称 |
| 过度概括 | “被广泛应用”“已有很多研究” | 中危；给具体数量/出处 |
| 数字幻觉 | 具体数字但无上下文/来源 | 高危；按L0处理 |
| “的”字堆叠 | 一句3+“的”，定中结构过长 | 中危；挑最累的20—30句拆短 |
| 跨节复述 | 同一发现在摘要、发现、结论、贡献重复四次 | 中危；每次换角度，不换词重复 |

**v3 新增：复述检查。** 同一发现出现四次不是错，但第四次应回答“它在理论/实践上意味着什么”，而不是把第三次的话再说一遍。

### L6 引用层（P1）

| 特征 | 典型模式 | v3 判定 |
|---|---|---|
| 格式不一致 | 混用[1]、[作者,年份]、脚注 | 中危；统一顺序编码 |
| 引用位置固定 | 所有引用都在句末 | 中危；关键概念首次出现就引 |
| 引用量过低/过高 | 文献综述每段0引，或每句都引 | 按章节类型判断，不按统一数值 |
| 泛化引用 | “研究表明……”无作者/年份 | 高危；补具体文献 |
| 引用与论点不匹配 | 引了但和上下文无关 | 中危；删或换 |
| **一条多文献** | 一个编号下合并多份公告/年报 | 高危；一条一号，系列报告可合并但需注明 |
| **逐事实引用缺失** | 一句话两个事实，只给一个范围号 | 中危；分别标注或拆句 |
| **来源不可追溯** | 只有首页URL、无公告名/日期/编号 | 中危；补全 |
| **来源过期** | 数据截止日已过，未更新最新季度 | 高危；按L0处理 |

**v3 新增：引用密度按章节类型。**

| 章节类型 | 建议密度 | 说明 |
|---|---|---|
| 文献综述/理论基础 | 每段1—2个引注 | 主要研究工作、概念、争论 |
| 分析框架 | 每个 borrowed construct 至少1个引注 | 自己提出的框架不必每段引，但借用的理论要引 |
| 案例分析 | 每个数据表/小节有来源注；外部事实引具体公告 | 不要求每段都引，但不能让数字悬空 |
| 结论/启示 | 与文献对话时引；纯结论不引 | 不要求每段引 |

### L7 元书写/自指层（P2）

| 特征 | 典型模式 | v3 判定 |
|---|---|---|
| 承诺性表述 | “将在下一节讨论”“详见后文” | 高危；删，直接写 |
| 框架提醒 | “本文的结构安排如下”“本节将从以下方面阐述” | 中危；删或改成一句自然过渡 |
| 过度结构化 | “本节分为三个部分：第一部分……第二部分……” | 高危；删计数，直接进入 |
| 不必要预览 | 段末预告下一段 | 中危；删 |
| 自我澄清 | “需要指出的是”“需要说明的是” | 中危；直接说 |
| 宣告式表达 | “本文正是对这一空白的回应” | 高危；直接陈述做了什么 |
| 优先权声明 | “首次”“首创” | 中危；除非有检索证据，否则删 |
| 概念对举泛滥 | 一段两次以上“不是A而是B” | 中危；保留一次，其余改写 |
| **计数句** | “本文有X个目的/意义/层面/创新” | 高危；删计数，直接写内容 |
| **写作史** | “本文之前把阶段模型改为条件模型”“上一版……” | 高危；论文不写改稿史 |
| **自我削弱** | “阶段顺序不是必然的”“本文只是抛砖引玉” | 中危；改成“本文数据显示/本文样本中” |
| **作者自称** | “作者认为”“作者计算” | 中危；改“本文认为”或删主语；“由作者计算”在数据注中可保留 |
| **“提醒我们”** | “某案例提醒我们……” | 中危；改“说明/表明” |
| **“本文”集群** | 连续3+段以“本文”开头 | 中危；换主语 |

**v3 新增：前后文引用规则。**

- 向前引用：用“第X章+内容名”，如“第5章的过程追踪”；不要用“后文/下文”。
- 向后回指：可以具体到节，如“5.4.5的反向案例”；不要用“前文已经说过”。
- 图表引用：用“图X-X/表X-X”，不要用“下图/上表”。

### 2.8 七类浮夸文风禁令

| # | 类型 | 说明 | 示例 |
|---|---|---|---|
| 1 | 学术装饰 | 不必要的学术定语和修饰词 | “探索性双案例比较”→“双案例比较” |
| 2 | 大词 | 超出论证需要的概念升级 | “范式转换”→“转变” |
| 3 | 文学隐喻 | 把信息陈述包装成画面描写 | “照亮了转型的一个侧面”→“各有分工” |
| 4 | 冗余修饰 | 同一信息用不同措辞重复强调 | “差异鲜明”+“差异如此之大”→删一个 |
| 5 | 学术黑话 | 圈内术语堆叠，外行不透明 | “多维度协同展开”→“技术、组织、生态系统的同步变化” |
| 6 | 渲染句式 | 用情节感替代事实陈述 | “并非孤立事件”→“同期出现” |
| 7 | 口号式表达 | 压缩口号替代具体描述 | “一客一策”→“个性化适配” |

## 3. 误报控制（v3 的核心）

### 3.1 四问法

规则命中后，先问：

1. **这是学科术语吗？** 本文定义的“维度”“场景”“收费锚点”“嵌入”，不是 AI 黑话。
2. **这是数字范围吗？** “2019—2022”“74.8%—60.6%”是范围号，不是修辞破折号。
3. **这是合法的概念对举吗？** “不是让软件更聪明，而是降低预测成本”——A 是真实误解，保留。
4. **这是具体分析角度吗？** “从亏损看/从粘性看/从回报看”是维度，不是空洞过渡。

### 3.2 常见误报表

| 模式 | 误报原因 | 正确处理 |
|---|---|---|
| 场景/维度 | 学科框架术语 | 加入白名单；只有装饰性用法才改 |
| 不是A而是B | A是真实误解/常见误判 | 保留；只有A是稻草人或一段两次以上才改 |
| 通过……使…… | “通过浏览器使用”是工具状语 | 只查“通过A使B”的因果句 |
| 从……看/角度 | 具体维度/文献归属 | 保留；只查“从某种角度” |
| —— | 年份/数字范围、术语连接号、表格缺省号 | 不查；只查修辞破折号“——”。`2019—2022`、`亏损—粘性—回报`、表格里的“—”都不是修辞破折号 |
| 第一/第二/第三 | 真实分类 | 保留；每段都用或代替推理才查 |
| 本文 | 学术自指 | 看密度和段落开头集群，不按总次数 |
| 这说明 | 结论句 | 可保留；连续出现才换“这意味着/由此可知”或直接写含义 |

### 3.3 误报处理

在诊断报告中单列 `false_positives`，不要混进 P2 改写清单。误报不进入改写计划，避免“为了去AI味把术语改错”。

## 4. S1—S10 改写策略

### S1 词汇替换

- 删一个 AI 空壳词，补一个具体事实；不删不补 = 文字变弱。
- 学科术语先查白名单；白名单里的词不换。
- “核心/关键/重要”不要整段重复；换成具体作用。

### S2 句式破形

- 长短交替：一段5—7句，最短<20字，最长>40字。
- 拆分号长句：一句3+分号，优先拆成2—3句。
- 删章节目录句：结构交给图1-1/1-2，正文不逐章复述。
- 去三连排比：三个动词只留一两个重点。
- 概念对举：一段最多一次；A必须是真实误解。

### S3 段落重塑

- 删计数句：不要“本文有X个目的”，直接写目的。
- 换开头主语：研究问题、分析框架、案例选择、数据来源、本章。
- 长短段交替：长论述中插1—2句短段。
- 一段一层：不要把三个论点塞进一段。

### S4 论证深化

- 补中间推理：A→C之间加A→B→C。
- 加边界条件：说明适用/不适用。
- 弱化因果链：“这使得”→“这种情况下”。
- 强因果动词降格：按“证据强度降格表”处理。

### S5 信息增密

- 模糊词换具体值：“相关研究”→“7篇文献/3家企业”。
- 删同义重复：保留信息最丰富的一句。
- 拆“的”字长定语：一句3+“的”，挑最累的拆。
- 数字补四要素：期间/单位/口径/来源。

### S6 元书写清理

- 删承诺、去预告、删计数句。
- 删写作史：“本文之前把X改为Y”不写进论文。
- 去自我削弱：“不是必然的”→“本文数据显示”；“只是抛砖引玉”→“本文的边界是”。
- “提醒我们”→“说明”；“作者认为”→“本文认为”或删主语。
- 前后文引用按“第X章+内容名”。

### S7 事实校验

- 每个数字过四要素。
- 每个公司事实查最新公告。
- 每个财年/自然年/半年/单季标注。
- 摘要/正文/表格/附录/封面/文献日期对账。

### S8 论证降格

- 决定→同时出现/相关；证明→与……一致；必要条件→先行条件；不可能→样本中未出现；越……越……→两个案例中呈现。
- 缺失数据→不可判定。
- 样本内构造/检验→说明/应用，并披露选择偏误。

### S9 引用对账

- 一条一号；系列报告可合并但注明。
- 逐事实引用：一句话两个事实，分别标注。
- 来源可追溯：公告名、日期、编号/URL。
- GB/T 7714 顺序编码制。

### S10 回归审计

见第 7 节。

## 5. 诊断评分与报告

### 5.1 优先级

| 级别 | 内容 | 处理顺序 |
|---|---|---|
| P0 | 事实、口径、来源、图表题注、跨章节不一致 | 先改；不改完不进入文风 |
| P1 | 论证强度、引用对账、样本内构造/检验 | 其次 |
| P2 | 词汇、句式、段落、信息密度、元书写 | 最后 |

### 5.2 层级风险

每层按“命中数/正文规模”和“语境判断”给低/中/高，不直接按词频定罪。

- 低：少量命中，且多数可保留；
- 中：命中集中，影响阅读或论证；
- 高：命中密集，或出现P0事实错误。

## 7. R 回归审计（v3 新增）

改完后逐项打勾：

### 7.1 数字与事实

- [ ] 摘要中的每个数字都能在正文/表格找到对应；
- [ ] 同一数字在摘要、正文、表格、附录一致；
- [ ] 每个百分数有期间、单位、口径；
- [ ] 财年/自然年/半年/单季标注清楚；
- [ ] 公司事实（总部、上市地、代码、CEO）为最新；
- [ ] 数据截止日与封面/附录一致。

### 7.2 引用

- [ ] 正文[N]与参考文献一一对应；
- [ ] 编号连续、无跳号；
- [ ] 一条一号；不同公告/年报未合并；
- [ ] 同一文献多处引用使用同一编号；
- [ ] 每个具体事实有对应来源；
- [ ] 来源可追溯（公告名/日期/编号/URL）。

### 7.3 图表

- [ ] 每幅图/每张表在正文有引用；
- [ ] 图题/表题不含“数据见正文”；
- [ ] 表注/图注有数据期间和口径；
- [ ] 图表清单页码为题注页；
- [ ] 图表编号连续、无重号。

### 7.4 目录与交叉引用

- [ ] 目录页码与正文标题页一致；
- [ ] 图清单/表清单页码与题注页一致；
- [ ] 前后文引用用“第X章/节”，不用“后文/下文”；
- [ ] 图表引用用“图X-X/表X-X”，不用“上图/下表”。

### 7.5 PDF 与提交

- [ ] PDF 视觉无文字压图、无空白页；
- [ ] PDF 文本层可检索（引号、破折号、汉字无替换符）；

- [ ] 封面匿名、致谢占位、无作者/导师信息；
- [ ] 最终版补致谢、原创性声明、使用授权页。

## 8. 参考文献 GB/T 7714-2015

### 8.1 核心原则

1. **顺序编码制**：按正文首次出现顺序编号。
2. **连续编号**：正文用 [1][2][3]，列表连续。
3. **一一对应**：正文引用与列表条目一一对应。
4. **同一文献不重复编号**：同一文献始终用首次编号。
5. **一条一号**（v3 新增）：一个编号只对应一份独立文件；系列报告可合并，但要在条目中写明年份范围；不同性质的文件（10-K、公告、新闻）不得合并。

### 8.2 各类型格式

**期刊 [J]**
```
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```

**专著 [M]**
```
[序号] 作者. 书名[M]. 出版地: 出版社, 出版年.
```

**学位论文 [D]**
```
[序号] 作者. 题名[D]. 出版地: 出版单位, 年.
```

**报告 [R]**
```
[序号] 作者. 报告名[R]. 出版地: 出版单位, 年.
```

**在线资源 [EB/OL]**
```
[序号] 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
```

### 8.3 公司文件著录

- 10-K：`公司名. Annual Report (Form 10-K), Fiscal Year 2025[R]. SEC, 2026.`
- 10-Q：`公司名. Quarterly Report (Form 10-Q) for the Quarter Ended June 30, 2026[R]. SEC, 2026.`
- 8-K/业绩公告：`公司名. 公告标题 (Form 8-K, 2026-11-02)[R]. SEC, 2026.`
- 港股：`公司名. 2025年度业绩公告[R]. 香港交易所, 2026-03-27.`
- 招股书：`公司名. 招股书及会计师报告[R]. 香港交易所, 2025-12.`

### 8.4 常见错误

| ❌ | ✅ |
|---|---|
| 中英文分组排列 | 按首次出现顺序混排 |
| 英文作者名写全 | 姓全称+名首字母 |
| 一条编号合并多份公告 | 一条一号；系列报告注明范围 |
| 正文未引的文献列入 | 列表只收正文引用的文献 |
| 同一文献多编号 | 始终用首次编号 |
| 只有首页 URL | 公告名+日期+具体 URL/编号 |

## 10. 附：项目实践提炼的 12 条经验

1. 题目承诺必须与证据档位一致；只检验到“使用量收费”，题目就不要写“结果导向收费”。
2. 数据来源要按市场写：美股 10-K/10-Q，港股年报/招股书/业绩公告。
3. 增长率必须带年份；“亏损期年增”不是年份。
4. 判定期和后续期要分开；后续期数字只能作方向印证。
5. 一条引注只对应一份文件；公告、年报、新闻不合并。
6. 图表题名不写“见正文”；数据期间放表注。
7. 图表清单页码取题注页，不取正文引用页。
8. “不是A而是B”只在A是真实误解时用；不要为了气势造对举。
9. 不要写“本文之前把X改为Y”的写作史；论文只呈现最终论证。
10. 不要自我削弱；“不是必然的”改成“本文数据显示”。
11. “提醒我们”改“说明”；“作者认为”改“本文认为”或删主语。
12. 强因果动词要配强证据；配不上就降格，不要靠形容词撑。
